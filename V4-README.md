# OfficeStore V4 — Emerald Marketplace Redesign

Այս տարբերակը ամբողջությամբ վերաձևավորված է՝ օգտատիրոջ տրամադրած marketplace reference-ի visual rhythm-ի հիման վրա՝ առանց Farmora բրենդի/բովանդակության պատճենման։

## Փոփոխված հիմնական ֆայլերը
- `src/pages/HomePage.jsx`
- `src/components/Layout.jsx`
- `src/components/ProductCard.jsx`
- `src/styles/main.css`

## Դիզայնի ուղղություն
- emerald green + white + soft gray palette
- compact announcement bar
- search-first header և category navigation
- լայն rounded hero
- horizontal category showcase
- dense 4-column product merchandising grid
- compact add-to-cart product cards
- promotional banner clusters
- discount / weekly best-seller / limited-deal sections
- dark green oversized-wordmark footer
- նույն visual language-ը Shop / Category / Product / Cart / Checkout / Account էջերում
- responsive mobile/tablet layouts

## Գործարկում
```powershell
npm.cmd install
npm.cmd run dev
```

Հետո բացել՝ `http://localhost:5173/`

Եթե browser-ը պահել է նախորդ տարբերակը՝ `Ctrl + Shift + R`։
